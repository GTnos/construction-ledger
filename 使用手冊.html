setup & usage guide

工程收支帳務系統

工程／裝修收支管理 · 多人連線、即時同步、發票拍照自動辨識

使用手冊

00 這是什麼

一個跑在自己電腦（或 NAS）上的小型記帳系統，專為工程／裝修類的收支管理設計。 啟動後，家人、夥伴用手機或電腦打開同一個網址，看到、修改的都是同一份資料， 不需要另外傳 Excel 或對版本。每筆新增、修改、刪除都留有紀錄，改錯了也能復原。

01 安裝與啟動

只需要做一次，之後每次要用就直接雙擊啟動檔即可。

1

安裝 Python 3（如果電腦還沒有）

到 python.org/downloads 下載安裝。 Windows 使用者請注意：安裝畫面最下面要勾選「Add python.exe to PATH」， 沒勾之後啟動腳本會找不到 Python。Mac 較新版本通常需要自行安裝，較舊版本可能已內建。

2

解壓縮收到的資料夾

放到桌面或「文件」之類你平常找得到、且不需要特殊權限的資料夾。 資料夾裡有 ledger（程式本體）、兩個啟動檔，之後所有記帳資料也會存在這個資料夾底下， 不要把 ledger/data 這個子資料夾刪掉或搬走。

3

雙擊啟動

🪟 Windows

雙擊 啟動-Windows.bat

🍎 Mac

雙擊 啟動-Mac.command。第一次可能被 Gatekeeper 擋下， 到「系統設定 → 隱私權與安全性」按「強制打開」即可。

看到黑底視窗顯示連線網址，就是啟動成功——這個視窗請不要關閉， 關閉視窗等於把伺服器關掉，其他人就連不上了。

4

開啟網頁、建立你的管理者帳號

瀏覽器打開 http://localhost:8123。因為是全新安裝， 第一次會直接看到「建立管理者帳號」的畫面，設定好帳號密碼即可—— 這組帳號有完整權限（刪除、匯入資料、管理其他人帳號），請自己保管好。

5

手機也能用，跟電腦共用同一份資料

手機連到跟電腦同一個 Wi-Fi，瀏覽器輸入 http://電腦的區網IP:8123。 區網 IP 怎麼查：Windows 開始選單搜尋 cmd，輸入 ipconfig 看 IPv4 位址； Mac 到「系統設定 → 網路」看目前連線的 IP。兩邊看到、改到的會是同一份資料，即時同步。

02 選用：發票拍照自動辨識

這個功能需要一組 Google Gemini API 金鑰（個人用量在免費額度內完全夠用）。不設定也沒關係， 其他功能都正常，只是拍照不會自動帶入金額，改成手動輸入即可。

1

用 Google 帳號登入 aistudio.google.com/apikey

2

按「Create API Key」，建立後複製那串金鑰文字。

3

在 ledger 資料夾的上一層（跟 ledger、兩個啟動檔同一層） 新增一個純文字檔，命名為 API.txt，把金鑰貼進去存檔——檔案裡只放金鑰這一行文字就好。

4

關掉伺服器視窗，重新雙擊啟動檔，設定就會生效。

注意

金鑰是一段文字，等同密碼，不要把 API.txt 或整個資料夾上傳到公開的地方。

03 使用教學

projects

建立專案

首頁按「＋新增專案」輸入名稱即可。每個專案的資料、帳號權限、修改記錄都各自獨立，可以同時管理好幾個工程案。

bookkeeping

記帳

「支出」「收入」「保證金」分頁裡直接新增紀錄。未登入只能查看（唯讀），登入後才能新增、修改。

invoice ocr

拍照上傳發票

支出表單按「拍照上傳發票」，手機會直接叫出相機。拍完自動辨識店家、日期、金額、統編， 確認無誤（手寫收據務必核對）後存檔。同一張發票要拆給好幾筆支出， 第二筆之後在表單按「選擇既有發票」就好，不必重拍。

team

邀請家人／夥伴一起用

管理者登入後到「使用者管理」新增帳號，把帳號密碼給對方，請他們打開同一個網址登入即可。

audit trail

修改記錄與復原

「修改記錄」頁列出所有新增、修改、刪除，含時間、操作人、改了哪些欄位。管理者可以針對單一筆按「恢復」，改壞、改錯都救得回來。

backup

備份

定期複製整個 ledger/data 資料夾就是完整備份；也可以在網頁裡各專案按「匯出 JSON」，但匯出的 JSON 不含發票照片本體。

04 常見問題

電腦睡眠或關機後，手機打不開怎麼辦？
啟動伺服器的那台電腦要保持開機、且啟動視窗開著，其他裝置才連得上——這台電腦扮演的角色類似小型伺服器。如果之後想要不依賴某一台電腦常開，可以考慮改放到 NAS 或雲端主機上執行。
忘記管理者密碼怎麼辦？
目前沒有「忘記密碼」自助流程。可以直接刪除 ledger/data/users.json 這個檔案（其他資料不受影響），重新啟動伺服器後會回到「建立管理者帳號」畫面，重新設定一組新的。
想換一台電腦繼續用怎麼辦？
把整個資料夾（含 ledger/data）複製到新電腦，用同樣方式雙擊啟動即可，資料完全帶著走。

05 安全提醒

請注意

這個系統沒有 HTTPS 加密，設計上只適合在家用或公司內網使用。 請不要透過路由器把 8123 連接埠對外（網際網路）開放，也不要把整個資料夾（尤其是 data 和 API.txt） 上傳到公開的雲端硬碟或分享連結。
